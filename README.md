# 🎨 Учёт граффити в Казани (Telegram, VK, сайт)

Проект для гражданского мониторинга **несанкционированного граффити**: фото, координаты и описание попадают в общую базу и на карту. Доступны Telegram-бот, бот сообщества VK и веб-страница с формой.

**Безопасность:** ключи Telegram, VK и `SECRET_KEY` храните только в `.env` на сервере (файл в `.gitignore`). Если токен попал в чат или в репозиторий — **немедленно перевыпустите** его у [@BotFather](https://t.me/BotFather) или в настройках сообщества VK. В репозитории должны быть только шаблоны вроде `.env.example`.

**VK и сайт:** заявки из VK сохраняются в ту же SQLite и попадают на публичную карту (`/public-map`), что и заявки с главной страницы. На продакшене задайте `PUBLIC_SITE_URL` (HTTPS), чтобы в ботах были верные ссылки.

## 📋 Возможности

### Для граждан:
- 📍 **Сообщить о граффити** — отправка фото/видео с геолокацией
- 📊 **Мои заявки** — просмотр статуса своих обращений
- 🗺️ **Карта** — интерактивная карта проблемных мест
- ℹ️ **Информация** — о проекте, работе сервиса и контактах
- 🔒 **Анонимность** — возможность анонимной отправки сообщений

### Для операторов / служб учёта:
- 📋 **Панель управления** — статистика и обзор заявок
- 📁 **Просмотр заявок** — детали, медиафайлы, история
- ⚙️ **Управление статусами** — изменение статуса с комментариями
- 🗺️ **Интерактивная карта** — визуализация всех случаев

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка

Скопируйте файл `.env.example` в `.env` и заполните:

```bash
# Telegram Bot Token (получить у @BotFather)
BOT_TOKEN=your_bot_token_here

# Адрес хоста и порт для веб-панели
WEB_HOST=127.0.0.1
WEB_PORT=8000

# Продакшен: публичный URL сайта (без завершающего /), например https://mysite.ru
PUBLIC_SITE_URL=

# Ссылка «Напишите нам во VK» на лендинге (опционально)
VK_GROUP_PUBLIC_URL=https://vk.com/clubXXXXXXXX

# VK Long Poll — токен и числовой id группы без минуса
VK_TOKEN=
VK_GROUP_ID=

# Путь к базе данных
DATABASE_PATH=data/antidrug.db

# Путь для загрузки медиафайлов
MEDIA_PATH=media

# Секретный ключ для сессий
SECRET_KEY=your_secret_key_here
```

### 3. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя и username для бота
4. Скопируйте полученный токен в файл `.env`

### 4. Запуск

```bash
python main.py
```

После запуска:
- **Бот** будет ожидать сообщения в Telegram
- **Веб-панель** доступна по адресу: http://127.0.0.1:8000

### 5. Вход в веб-панель

По умолчанию доступны учётные записи:
- `admin` / `admin123`
- `operator` / `operator123`

**⚠️ Важно:** Смените пароли в файле `web/app.py` перед развёртыванием!

## 🎯 Как использовать

### Гражданам:

1. Найдите бота в Telegram (по username, который вы задали)
2. Нажмите `/start`
3. Выберите «📍 Сообщить о граффити»
4. Отправьте геолокацию места
5. Прикрепите фото или видео
6. Добавьте описание (по желанию)
7. Получите номер заявки

### Операторам панели:

1. Откройте веб-панель: http://localhost:8000
2. Войдите под учётной записью
3. Просматривайте заявки на «Панели управления»
4. Изменяйте статусы:
   - 🆕 Новая → ⏳ В работе
   - ⏳ В работе → ✅ Завершена / ❌ Отклонена
5. Добавляйте комментарии к изменениям

## 🗺️ Карта

Карта отображает зарегистрированные точки граффити с цветовой индикацией статусов:

- 🔵 **Синий** — Новая заявка
- 🟠 **Оранжевый** — В работе
- 🟢 **Зелёный** — Завершена
- 🔴 **Красный** — Отклонена

## 📊 Статусы заявок

| Статус | Описание |
|--------|----------|
| 🆕 Новая | Заявка получена, ожидает обработки |
| ⏳ В работе | Специалисты выехали на место |
| ✅ Завершена | Надпись удалена |
| ❌ Отклонена | Заявка не подтвердилась |

## 🔒 Безопасность и анонимность

- Пользователи могут выбирать анонимный режим
- Данные пользователей не передаются третьим лицам
- Пароли хранятся в коде (для продакшена используйте БД с хешированием)

## 🛠️ Технологии

- **Backend:** Python 3.8+
- **Telegram Bot:** aiogram 3.x
- **Web Framework:** FastAPI
- **Database:** SQLite + aiosqlite
- **Templates:** Jinja2
- **Maps:** Leaflet + OpenStreetMap

## ☁️ Публикация на GitHub и интернет

1. Загрузите код в репозиторий **без** `.env`, без `*.db`, без содержимого `media/` (они уже перечислены в `.gitignore`).
2. Разместите приложение там, где крутится Python (VPS, [Railway](https://railway.app/), [Render](https://render.com/), и т.п.): процесс должен выполнять `uvicorn web.app:app --host 0.0.0.0 --port $PORT` и иметь доступ к записи каталогам `data/` и `media/`.
3. В переменных окружения сервера укажите `PUBLIC_SITE_URL=https://ваш-домен`, `VK_TOKEN`, `VK_GROUP_ID`, `SECRET_KEY`, при необходимости `DATABASE_PATH`.
4. Проверьте, что с телефона открываются главная страница, `/public-map` и сообщение после заявки из VK ведёт на этот домен.
