# Инструкция: Выгрузка проекта на GitHub и деплой на Render.com

## 2. Файлы конфигурации для Render

Render требует следующие файлы в корне проекта:

### 2.1 Procfile
Создайте файл `Procfile` (без расширения) с содержимым:
```
web: uvicorn web.app:app --host 0.0.0.0 --port $PORT
worker: python -m vk_bot.main
```

### 2.2 runtime.txt
Создайте файл `runtime.txt` с указанием версии Python:
```
python-3.11
```

### 2.3 requirements.txt
Убедитесь, что `requirements.txt` актуален (уже есть).

## 3. Адаптация путей к данным

На Render файловая система ephemeral (временная), поэтому:
- SQLite база будет теряться при каждом перезапуске
- Медиафайлы также не сохраняются

**Рекомендации:**
1. **Использовать PostgreSQL** (лучший вариант) – Render предоставляет бесплатную базу.
2. **Использовать облачное хранилище** (например, AWS S3) для медиафайлов.
3. **Использовать SQLite с периодическим бэкапом** (для тестирования).

### 3.1 Изменение конфигурации для PostgreSQL
Если решите использовать PostgreSQL, нужно:
- Добавить `asyncpg` и `sqlalchemy[asyncpg]` в `requirements.txt`
- Изменить `database.py` для работы с PostgreSQL
- Получить строку подключения из переменной окружения `DATABASE_URL`

### 3.2 Альтернатива: оставить SQLite с указанием пути в `/tmp`
Можно изменить `config.py`:
```python
import os
DATABASE_PATH = os.getenv("DATABASE_PATH", "/tmp/antidrug.db")
MEDIA_PATH = os.getenv("MEDIA_PATH", "/tmp/media")
```
Но данные будут теряться при перезапуске.

## 4. Создание сервисов на Render

### 4.1 Веб-сервис (Web Service)
1. Зайдите на [render.com](https://render.com) и создайте новый Web Service.
2. Подключите репозиторий GitHub.
3. Настройки:
   - **Name:** `grafkazan-web`
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn web.app:app --host 0.0.0.0 --port $PORT`
   - **Plan:** Free

### 4.2 Фоновый worker (Background Worker)
1. Создайте новый Background Worker.
2. Подключите тот же репозиторий.
3. Настройки:
   - **Name:** `grafkazan-vk-bot`
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m vk_bot.main`
   - **Plan:** Free

### 4.3 Переменные окружения
Добавьте следующие переменные окружения для обоих сервисов:

| Переменная | Значение | Описание |
|------------|----------|----------|
| `BOT_TOKEN` | ваш токен Telegram бота | От @BotFather |
| `VK_TOKEN` | ключ доступа сообщества VK | Из настроек сообщества |
| `VK_GROUP_ID` | числовой ID группы | Без минуса |
| `SECRET_KEY` | случайная строка | Для сессий FastAPI |
| `PUBLIC_SITE_URL` | https://grafkazan-web.onrender.com | URL вашего веб-сервиса |
| `DATABASE_PATH` | /tmp/antidrug.db | Путь к SQLite (если оставляете) |
| `MEDIA_PATH` | /tmp/media | Путь к медиафайлам |
| `WEB_HOST` | 0.0.0.0 | Хост для веб-сервера |
| `WEB_PORT` | $PORT | Порт (автоматически) |
| `VK_GROUP_PUBLIC_URL` | https://vk.com/ваша_группа | Ссылка на сообщество VK |

## 5. Деплой и тестирование

1. После создания сервисов Render автоматически запустит сборку и деплой.
2. Проверьте логи на вкладке Logs.
3. Откройте URL веб-сервиса (например, `https://grafkazan-web.onrender.com`).
4. Проверьте главную страницу, карту (`/public-map`).
5. Отправьте тестовое сообщение в VK группу – бот должен ответить.

## 6. Проблемы и решения

### 6.1 Бот не отвечает
- Проверьте логи worker.
- Убедитесь, что `VK_TOKEN` и `VK_GROUP_ID` корректны.
- Убедитесь, что Long Poll включён в настройках сообщества.

### 6.2 Ошибки базы данных
- Если используете SQLite, убедитесь, что путь доступен для записи.
- Рассмотрите переход на PostgreSQL.

### 6.3 Медиафайлы не сохраняются
- Реализуйте загрузку в облачное хранилище (S3, Cloudinary) или используйте временное хранилище с пониманием, что файлы будут потеряны.
